# Suno Studio 6.0 Wild Architect — Dr. Constantine Edition

Cyberpunk-styled single-file prompt builder optimized for **Suno v6**.

## Features

- Live Style compiler (positive tags only, ≤1000 chars)
- Separate **Exclude Styles** output (plain terms for the Exclude field)
- Harmonic steering chips (circle of fifths + devil’s tritones)
- Wild DSP mutators and Chaos Engine
- Bar-mapped lyric architect with meta-tags
- Presets including LOOPENS_TYRANNI, NEON_G-FUNK, CYBER_DJENT, NORDIC_NOIR, ASTRAL_GOA, and harmonic dark
- Slider matrix with v6 recommendations (Variety low, Style Influence high)
- Optional Gemini AI enhancer (API key stored locally)
- Self-contained HTML — open `index.html` in any browser

## Usage

1. Open `index.html` in a modern browser.
2. Select chips, set BPM/key/meter, adjust sliders.
3. Copy **STYLE** into Suno’s Style field.
4. Copy **EXCLUDE** into Suno’s Exclude Styles field.
5. Copy lyrics + meta-tags into the Lyrics field.
6. Set Variety near 0 and Style Influence high for maximum prompt control.

## v6 Notes

- Avoid putting “no …” inside the Style field — use the dedicated Exclude Styles field instead.
- Front-load genre, BPM, key and primary instruments.
- Variety slider rewrites your prompt when high; keep it low for precision.

Built for experimental, polyrhythmic, and harmonically intentional generations.
